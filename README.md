# 🎨 Portfolio Cá Nhân - Trương Triệu Vy

Một website portfolio chuyên nghiệp được thiết kế đặc biệt cho sinh viên CNTT chuyên ngành Đồ họa kỹ thuật số.

## ✨ Tính Năng

### 🎯 Thiết Kế
- **Theme Pastel tím hồng** - Giao diện màu sắc dịu dàng, thân thiện với mắt
- **Chuyển đổi chế độ sáng/tối** - Nút toggle theme ở đầu trang
- **Responsive Design** - Hiển thị hoàn hảo trên mọi thiết bị
- **Hiệu ứng tương tác** - Animations, hover effects, và scroll reveal

## 🛠️ Công Nghệ Sử Dụng

```
HTML5: Cấu trúc semantic
CSS3: Styling, animations, gradients
JavaScript: Theme toggle, form handling, scroll effects
```

```
mypage3/
├── index.html          # File HTML chính
├── styles.css          # CSS với theme tím hồng pastel
├── script.js           # JavaScript cho tương tác
└── README.md          # File hướng dẫn này
```

## 🚀 Cách Sử Dụng

### Mở website
1. Click chuột phải vào file `index.html`
2. Chọn "Open with Live Server" (nếu cài VS Code extension)
3. Hoặc mở trực tiếp bằng trình duyệt

### Chuyển đổi chế độ
- Click nút **🌙/☀️** ở góc trên cạnh phải
- Chế độ được lưu tự động

## 💡 Mẹo Tùy Chỉnh

- Email: `truongtrieuvy@email.com`

### Thêm Dự Án Mới
Sao chép `.project-card` trong Projects và chỉnh sửa

### Thay Đổi Màu Sắc
Chỉnh sửa CSS variables trong `:root` trong `styles.css`
